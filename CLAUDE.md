# Правила проекта
- Спецификация: SPEC.md. Делай только тот этап, который я назвал.
- Код и идентификаторы на английском. Тексты для пользователя и комментарии на русском.
- TypeScript в строгом режиме. Секреты только в переменных окружения, пример в .env.example.
- Нейросеть только разбирает фразы. Суммы, итоги, даты и повторы считает код.
- Время храним в UTC (timestamptz), показываем в часовом поясе пользователя.
- Деньги храним в копейках (bigint), никогда не float.
- Схему БД меняем только новой миграцией, старые миграции не трогаем.
- В SPEC.md чего-то нет или есть противоречие: спроси, не придумывай.
- Telegram Bot API, OpenRouter, Supabase: сверяйся с актуальной документацией, а не с памятью.
